Orbital Data Explorer and Granular Data System REST Interfaces

The Orbital Data Explorer (ODE) is a web-based search tool developed at NASA's Planetary Data System's (PDS) Geosciences Node. Through ODE, users can search, browse, and download a wide range of PDS Mars, Moon, Mercury, and Venus data.

The Geosciences Node provides a simple web-based API that allows non-PDS web and processing tools to search for PDS products, obtain meta-data about those products, and download the products stored in ODE's meta-data database.

  • What is a REST API?
    • REST (Representational State Transfer) is an industry standard method of accessing remote data using HTTP protocols.

Granular Data System (GDS) REST Interface

The Orbital Data Explorer (ODE) also provides a set of "granular-level" query tools. This tools allow users select portions of a dataset based on location and other parameters.

  • What are granular queries?
    • More information about granular queries (PDF)
  • What does the GDS REST interface include?
    • Mars - MGS MOLA PEDR query tool
    • Moon - LRO LOLA RDR query tool
    • Moon - LRO Diviner RDR query tool
  • GDS REST features?
    • Direct (synchronous) and background (asynchronous) queries
    • Support for very large queries compared to the existing ODE query tools (especially using background queries)
    • Set of Javascript-based web query pages that use the GDS REST interface
